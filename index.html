Genera las dimensiones y sus niveles desde un JSON. Ver formato en "¿Cómo se usa?".
¿Cómo se usa? (formato y ejemplo)
configuracion (todo opcional):
• titulo y color_titulo — texto y color del título
• color_flechas — color de las flechas/rayitas
• color_borde_cuadros — borde de los cuadros de dimensión
• color_fondo, grosor_ejes, longitud_ejes
• angulos — { "inicio": 145, "paso": 51, "sentido": "horario" } o array [145, 180, ...]
• marcas_por_defecto — { "cantidad": 3, "nombres": ["..."], "radio_inicio": 50, "paso_radio": 35 }

dimensiones (cada eje):
• nombre — opcional (por defecto la clave)
• corte — niveles: strings, u objetos { "texto", "radio", "ox", "oy", "anchor" }
• radios — array de radios alineado a la lista
• angulo, estilo — { "color": "#hex" }

📋 Copiar JSON del diagrama actual exporta ángulos reales + radios + offsets exactos (round-trip completo).
